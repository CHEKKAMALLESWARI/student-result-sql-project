# Student Result Management System - SQL Project

This is my first SQL project where I created a student database and wrote 10 useful queries.

## What I did:
- Created Database: student_result_db
- Created Table: students (id, name, class, subject, marks)
- Inserted 10 student records
- Wrote 10 queries: Full data, Subject-wise topper, Total marks, Pass/Fail, 90+ toppers, Average, Top 3 students, Views etc.

## Tools Used:
- MySQL Workbench
- GitHub

## Queries Covered:
1. SELECT * 
2. GROUP BY, MAX(), SUM(), AVG()
3. CASE WHEN, ORDER BY, LIMIT
4. VIEW Creation
